# Minis Ultra UI 审计与重设计报告

> 依据：2026-11-18 对当前安装 APK 的全页面走查（首页 / 聊天 / 更多菜单 / 设置首页 / 30 个设置子页，共 31 张截图，见 `ui-audit/`），以及 Apple HIG（tab-bars、lists-and-tables、sheets、navigation、SF Symbols、Adopting Liquid Glass）与 ChatGPT iOS / Claude iOS / Termius 的信息架构惯例。
> 本报告只做设计与规划，未改动 APK。

---

```

├─ 顶栏：设置⚙︎ · 自动整理 · 搜索 · 定时任务 · Minis Ultra

├─ 底部：新建工作区文件夹 · 搜索 · 右下浮动"1/8"搜索球
```

## 二、不合理处与隐患（按严重度）

### P0 可用性缺陷
1. **设置子页没有返回按钮**。管理提供商 / 模型组 / Token 用量 / MCP 等子页顶栏只有标题和右侧操作，无返回键，只能靠边缘侧滑或系统返回。实测自动化和单手操作都容易直接退出 app。iOS 规范要求导航栏左侧必须有返回。
2. **设置是一屏 40+ 入口的超长列表**。8 个分组、部分组只有 1 项（外观只有"外观"、网络只有"网络"），滚动 6 屏才能到底，没有搜索、没有锚点。查找"断线重试"需要滚动 4 屏。
3. **首页顶栏 4 个图标 + 底部又一排"新建文件夹/搜索" + 右下浮动搜索球**，搜索出现两次（顶栏和浮动球），浮动球还遮挡列表内容。功能重复、层级混乱。

### P1 结构不合理
4. **"工具"分散在 4 个地方**：聊天 ⋮菜单里的工具、设置里的"工具"分组、设置里的"MCP/插件市场/技能"、首页"工具"工作区分组。用户无法形成"工具在哪"的稳定心智。
5. **Agent 行为参数（压缩阈值/重试次数/重试间隔/触发压缩次数/压缩后新开会话）与功能入口混排在同一组**，高级参数应收进二级页"Agent 运行时"。
6. **"环境变量 / SSH 主机"放在 Agent 组**，但它们是全局凭据与连接配置，应与"权限/网络"同类。
7. **聊天 ⋮菜单 15 项平铺**，把"YOLO 全授权"这种高危开关和"打开浏览器"这种无害操作放在同一层级，且与"Token 用量/发送方式"状态项混排。
8. **会话列表即工作区列表**：分组 = 文件夹 = 工作区，概念三合一，"未读回复"这种系统分组和用户文件夹并列，语义不清。

### P2 视觉与一致性
9. **三个视觉体系并存**：深色渐变聊天背景 + 纯白设置页 + 半透明毛玻璃顶栏，切换页面时明暗跳变，没有统一的语义色板。
10. **图标风格混杂**：线性 emoji 风（⚙︎✨🕐）与实心图标混用，尺寸/描边不统一，应统一为 SF Symbols 风格的单色素图标。
11. **聊天输入区 5 个控件一行**（附件/展开编辑/斜杠/发送方式/发送），"发送方式"又是文字又是下拉，拥挤且与 ⋮菜单里的"发送方式"重复。
12. **Token 行"↑241k ↓11k · 缓存90%"裸排在消息流里**，对普通用户是噪音，应收进消息详情或状态栏。

### 隐患（非纯视觉）
13. **YOLO · 全授权**入口过浅（两级可达、无二次确认暗示），一旦误开，后续所有 shell/文件操作不再确认 —— 高风险操作需要独立"权限模式"页 + 明显状态条。
14. **API key / 环境变量 / SSH 主机**在设置里与常规项同层级展示，缺乏"敏感信息"分组与遮挡提示。
15. **流式输出期间"性能保护：简化渲染"常驻提示**，说明长会话渲染压力大；信息架构上应减少消息流内嵌卡片数量（工具卡/token 行）而不是只降渲染。
16. **无设置搜索**：40+ 入口只能靠记忆定位。

## 三、新信息架构（合并分组分类）

核心动作：**四 Tab + 设置分组收敛 + 聊天工具收口到 Sheet**。

```
Tab 1 会话          Tab 2 工具箱          Tab 3 任务         Tab 4 我的
├ 大标题+搜索        ├ 终端               ├ 定时任务          ├ 模型与提供商
├ 置顶/未读          ├ 浏览器             ├ 进行中的 Agent    ├ 外观
├ 工作区文件夹       ├ Git 面板           ├ 后台与通知        ├ Agent 运行时(二级)
│  ├ 制作           ├ SSH 工作区         └ 任务历史          │  ├ 多智能体
│  ├ 编程           ├ 文件/对话文件                          │  ├ 压缩与重试
│  └ …              ├ 技能                                  │  ├ 生命周期钩子
└ 右下 + 新会话       ├ MCP 集成                             │  └ 人格 SOUL
                     ├ 插件市场                              ├ 记忆
                     └ 在线工具                              ├ 连接(SSH/环境变量/网络)
                                                            ├ 权限与隐私(二级)
聊天页                                                       │  ├ 系统权限
├ 导航栏：‹ 会话名 ▾   K3 ▾   ⋯                               │  ├ 逐工具权限
│        （返回键常驻）                                       │  └ 隐私档位/YOLO
├ 计划条：可收起                                               ├ 数据与备份
├ 消息流（工具卡默认折叠）                                     │  ├ 存储/共享/挂载
├ 输入区：+  输入框  ↑                                        │  └ 备份与恢复
│   + → 底部 Sheet：附件/展开编辑/斜杠命令/发送方式             └ 系统(日志/关于/反馈)
└ ⋯ → 底部 Sheet（分组网格）：快捷 / 会话 / 工具 / 状态
```

合并对照：
- 设置 40+ 入口 → **8 组**，其中 4 组收进二级页，首屏一屏可见。
- 聊天 ⋮菜单 15 项 → Sheet 内 4 组，YOLO 移入"我的→权限与隐私"，菜单只保留状态指示。
- 顶栏"定时任务"→ Tab 3；顶栏"搜索"与浮动球 → 合并为大标题下搜索框。
- 输入区 5 控件 → 3 控件（+ / 输入框 / 发送），其余进 + 面板。
- 工具相关入口 → 全部汇聚 Tab 2 工具箱，聊天 ⋯ 里的工具只是快捷入口。

## 四、视觉规范（iOS）

| 项 | 规范 |
|---|---|
| 语义色 | systemBackground / secondarySystemBackground / label / secondaryLabel / separator / systemBlue，Light+Dark 双套 |
| 导航 | 首页/设置大标题(Large Title)，滚动收缩为居中标题；子页左侧必须有 ‹ 返回 |
| 列表 | inset grouped 圆角卡片，组头 13pt 全大写灰字，组尾脚注说明 |
| 弹层 | 底部 Sheet（圆角 12、Grabber），替代下拉菜单与全屏弹窗 |
| 图标 | 单色素 24pt 线性图标（SF Symbols 风格），禁用彩色 emoji 当功能图标 |
| 触感 | 切换/发送/确认给 haptic 反馈；危险操作用 systemRed + 二次确认 Sheet |
| 性能 | 工具执行卡默认折叠为一行"已执行 n 个工具 ›"；token 统计移入长按消息详情 |
| 深色 | 聊天不再用独立渐变背景，统一 semantic 背景，仅用户气泡用 systemBlue |

效果图见 `ui-redesign/index.html`（8 屏高保真）。
